# ROS 2 Packages

This workspace collects a set of ROS 2 packages, examples, and supporting assets that I use for learning and development. Each package keeps its own detailed notes and documentation.

## Packages

- [improved_obstacke_pkg](src/improved_obstacke_pkg): LiDAR-based obstacle avoidance package with separate scan and timer callbacks for responsive robot control.
- [template_proj_description](src/template_proj_description): Starter description package for a robot model, including launch files, RViz assets, and URDF/Xacro support.
- [vision_language_model_pkg](src/vision_language_model_pkg): Vision-language demo package with examples for segmentation and visual question answering.
- [learning_tf2_py](src/learning_tf2_py): ROS 2 tf2 Python tutorial package for learning transforms with TurtleSim-based examples.
- [Thirdparty](src/Thirdparty): Vendored third-party dependencies and shared external assets used by workspace packages.
- [Zenoh-PX4](src/Zenoh-PX4): PX4 and Zenoh integration package with benchmark scripts, telemetry tools, and offboard control examples.
